How uploading works

  1. Pick a division and dataset type. These are your company's standardized formats — each one has a fixed set of required columns.
  2. Your file's delimiter is detected automatically. Comma, semicolon, tab, or pipe-separated — the system figures it out and stores it as comma-separated, no need to tell it which one you used.
  3. Same format again? It won't create a new dataset — your file merges straight into the one growing dataset for that format.
  4. Decide how duplicates are handled. "Remove" skips repeats, "Replace" updates them with your new values, "Keep"/"Append" just adds everything.
  5. Other Format skips all of this — it's stored on its own, useful for one-off files that don't match a standard layout.

Not sure what a required column means? Check the "About this format" panel that appears once you pick a dataset type — it shows the current master dataset's size and recent uploads.
