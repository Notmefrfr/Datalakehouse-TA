How uploading works

  1. No division or dataset type to pick anymore. Just choose a file — the system compares its columns against every dataset you already have and matches it automatically.
  2. Your file's delimiter is detected automatically. Comma, semicolon, tab, or pipe-separated — the system figures it out and stores it as comma-separated.
  3. Matches an existing dataset? It appends straight in — any column the two sides don't share is simply left blank (null) for the rows that don't have it.
  4. Brings a brand-new column? If you're not an Administrator, the upload is held for an Administrator's approval before it's written. Administrators' own uploads apply immediately.
  5. Doesn't match anything at all? Give it a name in "New dataset name" above and it becomes a new dataset.
